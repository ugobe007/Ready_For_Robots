# Avidbots Neo — capability envelope

**Purpose:** Transfer-test input only. Robot → capabilities. No customer list. No industry account list.

## Can (robot actions)

- Autonomous **floor scrubbing** of hard indoor floors  
- Large contiguous indoor floor areas (commercial / industrial scale)  
- **Repeatable cleaning routes** on a schedule (often overnight / off-peak)  
- Human-shared spaces with appropriate safety / operational design  
- Commercial and industrial indoor environments (hospitals, airports, retail, warehouses, campuses, plants — as *environment types*, not seeded accounts)

## Cannot / weak

- Soft carpet deep-cleaning as primary mission  
- Stairs / multi-level without elevator+redeploy workflow  
- Outdoor yards, parking lots, weather-exposed decks as core  
- Disinfection claiming beyond scrubber physics (no magic sanitize marketing)  
- Ceiling, walls, windows, restroom fixtures as primary  
- Manipulation, transport of goods, inspection-as-primary, AMR tote move  

## Search vs action

- **Search with** EVS / custodial / floor-care / ride-on scrubber / auto-scrubber **workflows**  
- **Score as jobs** only after → autonomous recurring floor-scrub task decomposition  

## Explicit non-inputs

Do **not** seed:

- Known Avidbots / Neo customer names  
- Named airport / hospital / retailer account lists  
- “Where robots clean today” competitor maps  

Input is **this envelope only**. Discovery must come from open search on capability vocabulary.
