# Boston Dynamics Spot — capability envelope

**Purpose:** Extension-pressure test. Observe-a-target physics (not move-object, not scrub-surface).

## Can (robot actions)

- Mobile indoor/outdoor industrial **navigation** on legs  
- **Observe / inspect** targets along a repeatable route  
- Carry sensor payloads (RGB, thermal, acoustic — as configured)  
- Capture images / readings at waypoints for human review  
- Recurring inspection rounds in plants, yards, campuses  

## Cannot / weak

- Grasping / manipulation as primary (arm optional, not this envelope’s core)  
- Floor scrubbing · tote transport  
- Armed security response · human confrontation  
- Certified NDT judgment (robot captures; human interprets)  
- Long-haul multi-state travel as the “job” (Spot is site-local)

No known Spot customer list. No seeded nuclear/oil majors as accounts.
