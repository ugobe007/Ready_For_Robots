# Robot Automation Signal Ontology
## ReadyForRobots — Buying Signal Language Reference

**Version:** 1.0 — May 2026  
**Purpose:** Comprehensive taxonomy of words, phrases, and expressions that identify robot sales opportunities across 20+ industry verticals. Designed for use in signal detection systems, NLP classifiers, LLM prompts, and sales intelligence pipelines.

---

## How to Use This Document

This ontology is structured into four layers for each vertical:

1. **Pain Signal Words** — Single words that appear in job postings, press releases, earnings calls, OSHA filings, or news articles indicating automation readiness.
2. **Buying Signal Phrases** — Multi-word phrases (2–5 words) indicating active interest in or evaluation of automation.
3. **Trigger Expressions** — Full sentences or clauses that, when found in public sources, strongly indicate an imminent or active robot purchase decision.
4. **Job Title Signals** — Roles being hired that indicate automation investment is underway.
5. **CapEx and Financial Signals** — Budget and investment language indicating capital is being allocated for automation.
6. **Expansion and Facility Signals** — Language around new facilities, expansions, or redesigns that create robot purchase windows.
7. **Regulatory and Compliance Signals** — Industry-specific regulatory language driving automation adoption.

**Signal Categories** (aligned with ReadyForRobots platform taxonomy):

| Category | Description |
|---|---|
| **Operational** | Labor shortage, safety incidents, inefficiency indicators |
| **Growth** | Expansion, new facilities, contract wins, capacity pressure |
| **Financial** | CapEx announcements, budget allocations, investment rounds |
| **Intent** | Automation hiring, leadership changes, RFP language |
| **External** | Regulatory changes, competitor moves, industry events |

## Integration Notes for Signal Detection System

### NLP Matching Strategy

**Exact phrase matching** (highest confidence): Use for Trigger Expressions — these are high-specificity multi-word patterns that rarely appear in non-automation contexts.

**Fuzzy/semantic matching** (medium confidence): Use for Buying Signal Phrases — allow for word order variation and synonym substitution (e.g., "reduce labor costs" ≈ "lower workforce expenses").

**Keyword presence** (lower confidence, requires co-occurrence): Use for Pain Signal Words — a single word like "shortage" is only meaningful when co-occurring with industry context words (e.g., "shortage" + "workers" + "warehouse").

### Recommended Co-occurrence Rules

A signal should only be scored if at minimum **two** of the following are present in the same document or within a 30-day window for the same company:

1. One or more Pain Signal Words from the relevant vertical
2. One or more Buying Signal Phrases
3. A Job Title Signal (active posting)
4. A CapEx or Expansion Signal
