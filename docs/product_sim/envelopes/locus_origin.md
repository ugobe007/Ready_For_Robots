# Locus Origin — capability envelope (updated)

## Can (robot actions)
- Indoor warehouse / fulfillment / 3PL mobile navigation with associates  
- **Transport** totes, cartons/boxes on robot, carts, completed picks  
- Point-to-point / pick→pack / putaway / replenishment **movement**  
- Reduce non-value-added **picker travel** (“people pick, robots move”)  
- Multi-robot fleets; chilled with mods (public HelloFresh)

## Cannot / weak
- Autonomous grasping / shelf picking / case manipulation off rack  
- Forklift / heavy pallet racking  
- Outdoor, stairs-primary, scrubbing, pure inspection  
- Lights-out AS/RS replacement  

## Search vs action
- **Search with** order selector / case picking / replenishment (workflows)  
- **Score as jobs** only after → transport/travel task decomposition
