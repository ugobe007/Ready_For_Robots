# Self-audit protocol — 10 robots × 25 jobs

**Goal:** Measure product performance without waiting for meetings.

## Method

1. Pick **10 robots** across categories (AMR, forklift, scrubber, cobot, inspection, humanoid, tugger, pallet AMR, food, ag — or best available in RFR catalog).  
2. Write a **capability envelope** (can / cannot) from public specs — ½ page max.  
3. Generate **top 25** job-discovery results each (capability → work → where → why now).  
4. Manually audit every row with four yes/no:

| # | Question |
|---|----------|
| Q1 | Does this work **probably exist**? |
| Q2 | Could **this robot** plausibly perform it? |
| Q3 | Is the result **non-obvious**? |
| Q4 | Would investigating further be **rational** for a salesperson? |

5. Tally /250.

## Pass intuition (not sacred)

| Metric | Encouraging | Concerning |
|--------|-------------|------------|
| Q1 | &gt;200/250 | &lt;100 |
| Q2 | &gt;180/250 | &lt;80 |
| Q3 | &gt;120/250 | &lt;40 |
| Q4 | &gt;100/250 | &lt;30 |
