# Place is one next action — not a nested form

**Date:** 2026-08-25  
**Type:** build  
**Agents:** ProductSurface

## Goal

Step 03 still felt like an admin dump: nested 01 Pack / 02 Quote / 03 Apply inside FIND → jobs → Place. Reevo and Monaco feel inevitable because every screen has full context of the object and **one** next action. Copy that *feeling* for Robot Jobs. Cal stays frozen. Do not invent dollars.

## Acceptance

1. Job-list CTA is **Place these jobs →** (the punchline of step 2).
2. Place desk shows **Your move: {one action}** and only that lane’s control — no nested 1–2–3 grid.
3. Money click is explicit: **Lock this quote** after pack + rental + PoC; then **Place this job →**.
4. No SIGNAL buyers. No OEM roster. No Cal. No invented rental.

## Out of scope

Reevo TAM, sequences, forecasting, compounding email memory. Signed-in apply persistence.
