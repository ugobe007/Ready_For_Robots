# NIMO Technology — Beta / PoC Go-To-Market Strategy

**Company:** NIMO Technology — "Physical AI that feels." Tactile-first humanoid with a proprietary touch foundation model. Beachhead: commercial-kitchen back-of-house (cutting, portioning, multi-step assembly). Post-PoC, Stanford-founded, CSO Bob Christopher (ex-President, Richtech Robotics).
**Motion:** No-cost validation pilots (beta). Cal finds motivated early beta hosts to test and validate the robot — qualify on **fit + willingness**, not budget.
**Site:** https://nimotech-brscfv5x.manus.space/ · Contact: yimengq@nimotechs.com

---

## 1. What Cal is actually selling right now

Not a purchase. A **partnership**: NIMO installs the robot and provides engineering support at **no cost**; the beta host provides a real kitchen, a real workflow, staff time, structured feedback, and (ideally) a reference/case study. The "price" the host pays is **access, attention, and advocacy** — that is the qualification bar.

**The exchange:**

| NIMO provides | Beta host provides |
|---------------|--------------------|
| Robot hardware + install, on-site engineering support | Kitchen site, power/space, one real workflow to validate |
| Fine-tuning on their specific task (days–weeks) | A named champion + staff time for feedback loops |
| Success metrics + validation report | Permission to capture task data (improves the model) |
| Early-partner pricing when they convert | Reference / testimonial / case study rights |

## 2. The wedge (lead every conversation with this)

Vision-first humanoids (Tesla Optimus, Figure Helix, Physical Intelligence π0) can *see* a kitchen. **NIMO can *feel* it** — the contact-rich work (delicate handling, portion-by-feel, press-and-finish assembly) that vision-only arms fumble. One touch foundation model, every kitchen task, days to deploy, and every site makes the next one smarter (tactile data flywheel).

## 3. Beachhead ICP (who to beta first)

Start narrow where the environment is controlled and the decision is fast.

| Priority | Segment | Why they're an ideal beta host |
|----------|---------|-------------------------------|
| **1** | Ghost / cloud kitchens & virtual brands | Controlled layout, high repetition, single tech-forward decision-maker, automation believers |
| **1** | QSR innovation labs / high-volume franchisors | R&D budget + acute labor pain + repetitive menus; already piloting automation |
| **2** | Fast-casual assembly concepts (bowls, burritos, pizza) | Their core task = NIMO's demonstrated tasks; clean assembly line |
| **2** | Contract / institutional food service | Huge labor spend, central kitchens, standardized menus (longer cycle, bigger prize) |
| **3** | Commissaries / central prep kitchens | Repetitive prep, off-peak 24/7 runtime = great validation environment |

## 4. BETA-READY qualification rubric

Because there's no money gate, qualification protects NIMO's scarce engineering time. Score each 0–2; **pursue at ≥ 7/10**, fast-track at 9–10.

| # | Criterion | 0 | 1 | 2 |
|---|-----------|---|---|---|
| 1 | **Task match** — NIMO has demonstrated their exact workflow | Novel/unproven task | Adjacent to a demo | Exact match (cut/portion/assemble) |
| 2 | **Environment** — space, power, layout, safety | Chaotic/unsuitable | Workable w/ effort | Clean, controlled (e.g., ghost kitchen) |
| 3 | **Champion & speed** — engaged sponsor + decision path | No sponsor | Interested, slow | Founder/innovation lead, < 30-day yes |
| 4 | **Commitment** — staff time, feedback, reference rights | PR-only / won't commit time | Time but no reference | Time + data + reference |
| 5 | **Pain & volume** — labor pain + enough repetition to matter | Low volume/pain | Moderate | Acute labor pain + high repetition |

**Red flags (disqualify or park):** wants a free robot with zero staff engagement; PR-photo interest only; environment too variable for a first validation; no internal owner.

## 5. Pipeline stages (beta motion)

| Stage | Entry gate | Exit / success signal |
|-------|-----------|-----------------------|
| **0 · Target & qualify** | SIGNAL why-now trigger + fits ICP | BETA-READY ≥ 7 |
| **1 · Discovery call** | Reply / meeting booked | Task, pain, champion, environment confirmed |
| **2 · Tactile demo** | Discovery qualified | Demo of *their* task (eggs / portioning / their signature item) |
| **3 · Beta agreement** | Demo lands | Signed mutual beta MOU (no fee): scope, site, metrics, timeline, reference terms |
| **4 · Live validation pilot** | Robot installed | 2–6 wks: uptime, throughput, portion accuracy, labor-hours displaced |
| **5 · Convert** | Pilot validated | Design-partner LOI / paid multi-site RaaS + published case study |

**Pilot success metrics to lock in Stage 3** (so validation is objective): station uptime %, throughput (units/hr vs human baseline), portion/quality consistency, labor-hours displaced, defect/waste rate.
