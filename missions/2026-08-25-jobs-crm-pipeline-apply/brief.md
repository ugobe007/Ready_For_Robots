# Jobs CRM on pipeline: 5 jobs, Apply rectify, no SIGNAL OEMs

**Date:** 2026-08-25  
**Type:** build  
**Agents:** ProductSurface

## Goal

Step 02 checkboxes are obvious and keep **5** jobs. Next opens the **Jobs CRM desk on `/pipeline?src=jobs_activate`** — not SIGNAL leads or robot OEM shortlists. Checking jobs dumps them into that desk. **Apply to jobs** opens rectify + outreach: models, PoC evidence, monthly rental the robot company will charge (user-entered, never invented), whether the OEM/distributor has credentials to apply, how to fix gaps, then track application and follow-up.

## Acceptance

1. Job list: all 5 example jobs start checked; copy says so; checked rows are visually marked **Keep**.
2. Next → `/pipeline?src=jobs_activate` (signup hop if signed out). Desk shows up to **5** Job Cards from the handoff. No Hermes OEM vendor list. No SIGNAL buyer feed.
3. Select a job → Apply panel: credential gaps (model pack, PoC, monthly rental), how to fix, placement outreach draft. Apply enabled only when gaps are closed. Status: blocked → ready → applied → follow-up.
4. Header CRM on Jobs chrome points at the same desk. Bare `/crm` and `/pipeline` without Jobs `src` stay SIGNAL.
